## Built with

HTML, CSS and JavaScript, hosted on GitHub Pages. No build step.

- Fonts: Bricolage Grotesque and Hanken Grotesk, self-hosted (SIL Open Font Licence, in `fonts/`).
- The Warrior and the Thief: KayKit by Kay Lousberg (CC0), rendered with three.js from the game's own models (a still, a 21-frame turn and the game's Cheer animation).
- Every screenshot is a real capture of the project; each image's source is recorded in the `.json` file beside it.
- The design system is written down in `DESIGN.md`.
