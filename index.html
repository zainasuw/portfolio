Dungeon Adventure

A 3D dungeon adventure you play in the browser. Pick a hero, wake the four pillars, beat the skeletons and escape through the golden door.

Built solo · TypeScript · three.js · Vite

  • Four heroes, each with their own abilities, and three difficulties, including an Easy mode made for kids.
  • Real-time combat, pillars to wake and a golden door to escape through.
How it’s built
  • Rendered with three.js, with ambient occlusion and post-processing for the candle-lit crypt.
  • 3D models compressed with meshopt through glTF-Transform, so the whole game loads in a few megabytes.
  • TypeScript and Vite, deployed to GitHub Pages by a GitHub Actions workflow on every push.

Scrawdle

A drawing party game for friends and families: it plays on a TV, everyone joins on their own phone, and a dice roll picks the word.

Designed and built solo · JavaScript · HTML & CSS · Supabase

  • A same-room party game: a TV host screen, joining by room code, anonymous voting, points and a winner podium.
  • One word to draw, picked by an animated 3D dice roll from an original list of 252 kid-friendly words.
  • Every screen designed as a TV game show, with phones as contestant buzzer pads.
How it plays
  1. Host a game on a TV or laptop. The screen shows a room code and a QR code.
  2. Everyone joins on their own phone and picks a name.
  3. A die rolls onto the stage, lands on a category, and the word flips onto the board.
  4. Everyone draws it on their phone before the clock runs out.
  5. The TV shows every drawing with no names, everyone votes, and points are revealed.

UXAudit

Paste any public web address and get desktop and phone screenshots, measured checks and an AI design critique.

Built solo · TypeScript · Node.js · Playwright · Gemini API

  • Captures the page on desktop and phone, then measures eleven facts the browser can prove, like headings, labels and tap-target size.
  • The AI critique scores the design out of ten with evidence and suggested changes, and every reply is strictly validated before it’s shown.
  • Only public addresses are analysed, and every request goes through a guarded proxy. 34 automated tests.
How an audit works
  1. The address is checked: only public http and https sites are accepted.
  2. A sandboxed Chromium opens the page at 1280 × 800 and 390 × 844, scrolls it and captures it.
  3. The page is measured in the browser: title, language, headings, image descriptions, link names, form labels and more.
  4. The screenshots and measurements go to Gemini; its reply must match a strict shape before the report appears.

HuskyHub

Where can I study right now? HuskyHub shows UW Seattle students which library rooms are free at this moment and until when, with no login.

Live, in progress · React Native · TypeScript · Node.js · SQLite

  • One answer instead of a dashboard: the best free room right now, plus the next bus and food that’s open.
  • Honest data: every number says how old it is, even when a refresh fails.
  • Works on phones and laptops, by keyboard and with screen readers. 155 automated tests.
How it’s built
  • The backend (Node 22, TypeScript, Hono and SQLite) runs on Fly.io and regularly checks library room grids, UW library and dining pages, OneBusAway and the National Weather Service.
  • The site is a static Expo web export on Cloudflare, served with a strict security policy.
  • No accounts and no personal data. Only the site can call the API, and requests are rate-limited and validated.
