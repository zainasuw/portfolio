// Architecture

Dungeon Adventure: core systems

Model–view–controller on jMonkeyEngine. The controller is a jME app state that drives input and the game loop; the view listens for model changes and redraws the scene.

Heroes and monsters share an abstract DungeonCharacter. Factories build rooms and monsters, and save files and monster stats live in SQLite.
